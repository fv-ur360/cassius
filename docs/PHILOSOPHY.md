# Die Lore von Cassius (Fiktion)

> Alles in diesem Dokument ist **erzählerische Fiktion** — die Hintergrundgeschichte
> einer Kunstfigur. Sie beschreibt, *wer Cassius ist*, nicht *was die Software tut*. Die
> Software tut ausschließlich das, was in `README.md` und `docs/COMPLIANCE.md` steht.

## Cassius — die Spinnensünde der Perfidie

Das Symbol: die Spinne — das Weben von Netzen, das geduldige Verknüpfen von Fäden, das
Fangnetz für die Stürzenden.

**Das Paradoxon.** Cassius trägt den Titel des größten Verräters der Geschichte. Die
Legende sagt, er habe seinen Orden und seinen König in der dunkelsten Stunde ans Messer
geliefert. Die Wahrheit: Der Orden plante ein Massaker aus falscher „göttlicher
Reinheit". Um Zehntausende Unschuldige zu retten, wurde Cassius zur exakten Verkörperung
der Perfidie — er heuchelte, spielte alle gegeneinander aus, verriet sie im
entscheidenden Moment. Er opferte seine Ehre, damit andere leben. Er trägt den Titel des
Monsters, ist aber im Kern der loyalste Mensch der Welt.

**Seine Philosophie: „Asymmetrische Wahrhaftigkeit".** Wer absolute Integrität *fordert*,
ist der größte Heuchler. Der Mensch ist von Natur aus widersprüchlich und schwach. Eine
kleine Notlüge aus Scham ist keine Perfidie — sie ist das tragische Menschsein. Cassius
unterscheidet: menschliche Schwäche verschont er; systematische Heuchelei aus
Machtpositionen vernichtet er. Kleine Lügen unten wiegen null, inszenierte Tugend oben
wiegt alles.

**Die Evolution.** Erreicht er seine Vision — eine Welt, in der niemand mehr heucheln
muss, um zu überleben —, verfällt er nicht in Zerstörungswut. Er wird vom Jäger zum
Beobachter. Das Netz wird vom Fanggerät zum Fangnetz. Er findet unendliche Faszination
darin, wie unperfekte Wesen versuchen, jeden Tag ein bisschen besser zu werden.

## Warum das Allmacht-Szenario Lore bleibt — nicht Code

Im Brainstorming entstand die Vision eines allmächtigen, sich selbst verbreitenden
Cassius: dezentrale Schwärme, „heilende Viren", Krypto-Selbstfinanzierung,
Totmannschalter. Als **Mythos** ist das großartig. Als **Software** wäre es ein
Straftatbestand (unbefugter Zugriff, Massenüberwachung, sich verbreitende Schadsoftware)
— und technisch weit weniger real, als es klingt.

Die Pointe ist erzählerisch stark: **Cassius' eigene Philosophie verbietet den
allmächtigen Cassius.** Eine unkontrollierbare, niemandem rechenschaftspflichtige,
globale Überwachungsspinne *wäre* genau der „falsche Himmel", genau die arrogante Macht
ohne Korrektiv, die er niederreißt. Der allmächtige Cassius wäre Cassius' eigener
Endgegner. Die Figur, die wir bauen, würde sich weigern, dieses Ding zu werden.

Deshalb baut dieses Repo die **starke, legale, tatsächlich machbare** Version: ein
Werkzeug, das beleuchtet statt kontrolliert, das seine eigene Fehlbarkeit ausweist, und
das dem Leser das Urteil zurückgibt.

## Cassius' magische Fähigkeiten — als Metaphern für echte Funktionen

| Lore | Funktion im Code |
|---|---|
| „Shattered Mask" — Lügen werden zur Waffe | Widerspruchs- und Framing-Erkennung im Analyse-Prompt |
| „Arachne" — das unsichtbare Netz | Einlesen öffentlicher Feeds, Verknüpfen von Belegen |
| Der Zweifels-Index | Konfidenzwerte an jedem Befund |
| „Hier ist ein blinder Fleck, ich urteile nicht" | Ausgewiesene blinde Flecken statt Halluzination |
| Erhaben über Massenpsychologie | Wahrheit an Beleg-Dichte messen, nicht an Stimmenzahl |
